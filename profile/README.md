# mAirList

> One named mAirList hour. Finish the cart. Leave a note the next person can read.

## Session Card

| Slice | What you do in mAirList | What remains |
|-------|------------------------|--------------|
| Arrival | Open mAirList and name today's station desk | A titled playout log |
| Focus | Keep only live carts on the mAirList board | A short cartwall list |
| Check | Read mAirList playout log before the next break | A confirmed automation hour |
| Handoff | Mark finished carts inside mAirList | A note for the next visit |

## How mAirList Sits

mAirList does not replace the console, the cart library, or the transmitter log you already operate. It sits beside them as a named station desk for one job: which radio automation hour is live, which cartwall still matches the playout log, and what the next person should read before the next break.

## Traffic Light

| Signal | On the mAirList board | What you do |
|--------|----------------------|-------------|
| Green | Named hour, short live cart list | Continue the same log |
| Amber | Two hours mixed in one cartwall | Split the set before a break |
| Red | No title, no note, carts unlabeled | Stop and name the hour first |
| Clear | Handoff written, live carts few | Close mAirList and leave the desk |

![mAirList](https://www.mairlist.com/images/auto/full/mainwindow.png)

## Open Order

1. Open the last mAirList playout log, not a new empty station desk.
2. Read the cartwall and the last handoff.
3. Finish one visible cart inside mAirList.
4. Write what changed, then close with fewer unlabeled carts than you found.

## Desk Fit

| Who | What mAirList holds |
|-----|--------------------|
| Station desk | Radio automation, cartwall, and playout log you operate |
| Shared desk | One mAirList profile per person |
| Live hour | Named carts waiting for the next break |
| Support | A repeatable mAirList layout for the same log |

## After a Week

A week in mAirList is not a thicker unlabeled cart pile. It is the same title, a shorter live cartwall, and a note that still makes sense before the next break. Take finished hours off the live set so the next visit starts on the log that is still open.

## Sign-off

- [ ] The mAirList workspace name is short enough to scan
- [ ] Only live carts are on the board
- [ ] A second person can read the handoff
- [ ] The last mAirList log still opens after a restart

## Field Note

mAirList is easier to trust when the station desk stays smaller than the cart folder it came from. Name the hour, keep the live log, finish one visible cart, and write what changed.
